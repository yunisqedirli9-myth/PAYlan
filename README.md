PAYlan — Task Scheduler
PAYlan istifadəçilərin gündəlik tapşırıqlarını daha rahat idarə etməsi üçün hazırlanmış web əsaslı Task Scheduler layihəsidir. Layihənin əsas məqsədi istifadəçilərə tapşırıqları yaratmaq, prioritetləşdirmək, filterləmək və izləmək üçün sadə və müasir interfeys təqdim etməkdir.
Sistem vasitəsilə istifadəçilər hesab yarada, öz hesablarına yenidən daxil ola və bütün tapşırıqlarını yadda saxlanılmış şəkildə idarə edə bilirlər. Layihədə “High”, “Medium” və “Low” prioritet sistemindən istifadə olunmuş, həmçinin tapşırıqların statusa və prioritetə görə filterlənməsi təmin edilmişdir.
UI/UX hissəsində müasir və minimalist dizayn yanaşması tətbiq edilmiş, neon tonlu rənglər və responsive görünüş istifadəçi təcrübəsini daha rahat etmək üçün hazırlanmışdır.
Bu layihə HTML, CSS və JavaScript texnologiyalarından istifadə edilərək hazırlanmışdır və məlumatların saxlanılması üçün localStorage texnologiyası tətbiq edilmişdir.
